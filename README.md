# Swipe&Watch 2.0

Персональный кино-сервис: подбор по настроению, свайпы, сохранение сессий, личная коллекция и профиль. Backend остаётся на FastAPI + SQLAlchemy + PostgreSQL; клиентская часть переработана в адаптивное приложение без сборки Node.js.

## Что входит в 2.0

- Новый адаптивный интерфейс: главная, подбор, коллекция, история и профиль.
- Подбор по жанрам, формату, длительности, диапазону лет, минимальному рейтингу и возрастному ограничению.
- Сессии сохраняются на сервере и восстанавливаются после перезагрузки страницы.
- Личная коллекция с независимыми флагами: избранное, хочу посмотреть, просмотрено, пропущено.
- Личная оценка и заметка для фильма.
- История завершённых и незавершённых подборок.
- Отмена последнего свайпа с восстановлением предыдущего состояния.
- Экспорт коллекции и истории в JSON.
- Опциональная авторизация VK ID через OAuth 2.1 + PKCE. Без VK проект продолжает работать в гостевом режиме.
- PWA-манифест и кэширование статических файлов.
- Старые таблицы MVP сохраняются; новые функции используют дополнительные таблицы. При старте выполняется безопасное копирование старых лайков/просмотров/скипов в новую коллекцию.

## Запуск локально

Требуется Python 3.11+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env`, укажи `DATABASE_URL`, `SECRET_KEY`, `ADMIN_TOKEN` и при необходимости `KP_API_KEY`.

```powershell
python -m scripts.sync_catalog --budget 50
uvicorn app.main:app --reload
```

Открой http://localhost:8000. Swagger: http://localhost:8000/docs.

> Если каталог уже загружен в ту же базу данных, повторно запускать `sync_catalog` не нужно.

## Переменные окружения

| Переменная | Обязательность | Назначение |
|---|---|---|
| `DATABASE_URL` | Да | PostgreSQL / Neon connection string |
| `SECRET_KEY` | Да | Подпись гостевых и пользовательских токенов |
| `ADMIN_TOKEN` | Рекомендуется | Доступ к `/api/admin/*` |
| `KP_API_KEY` | Нет | Обогащение каталога данными Кинопоиска |
| `VK_CLIENT_ID` | Нет | ID приложения VK ID |
| `VK_REDIRECT_URI` | Нет | Точный callback, например `https://example.com/api/auth/vk/callback` |
| `VK_SERVICE_TOKEN` | Нет | Для конфиденциальных конфигураций приложения VK ID, если этого требует кабинет |

Для VK ID создай Web-приложение в кабинете VK ID, добавь точный Redirect URI, затем укажи `VK_CLIENT_ID` и `VK_REDIRECT_URI`. Авторизация реализована с PKCE; секреты VK не передаются браузеру. После входа анонимные данные объединяются с найденным VK-профилем. В гостевом режиме пользователь может работать и без VK ID.

## База данных и обновление существующей БД

`Base.metadata.create_all` создаёт новые таблицы, не удаляя существующие. При старте приложение также переносит старые состояния `liked/watched/skipped` в `user_movie_collection`, не меняя старые записи. Для продакшена перед обновлением рекомендуется сделать backup Neon.

Новые таблицы: `user_profiles`, `user_identities`, `user_movie_collection`, `swipe_state_snapshots`, `session_options`, `vk_oauth_attempts`, `auth_exchange_codes`.

## API

Основные маршруты:

- `POST /api/auth/anon` — гостевой профиль.
- `GET /api/auth/providers` — доступные способы авторизации.
- `GET /api/auth/vk/start` и `/api/auth/vk/callback` — VK ID OAuth.
- `POST /api/auth/exchange` — обмен одноразового кода входа на токен.
- `GET /api/meta`, `GET /api/health` — статус и каталог.
- `POST /api/sessions`, `GET /api/sessions/active` — создание и восстановление сессии.
- `GET /api/sessions/{id}/next`, `POST /events`, `/undo`, `/finish` — работа с подборкой.
- `GET /api/me/dashboard`, `/profile`, `/collection`, `/sessions` — личное пространство.
- `PUT /api/me/collection/{movie_id}` — изменение состояний фильма.
- `GET /api/me/sessions/{id}` — детали старой подборки.
- `GET /api/admin/stats`, `POST /api/admin/sync` — администрирование.

## Деплой

Dockerfile готов для платформ, поддерживающих Docker. Контейнер слушает порт `8000`; при необходимости платформенный порт можно настроить через переменную `PORT` (см. команду запуска вашей PaaS). Для VK ID укажи публичный адрес callback в кабинете VK ID и в `VK_REDIRECT_URI`.

## Что важно знать

- В ZIP не включается `.env`; скопируй свои секреты в переменные окружения хостинга отдельно.
- Гостевой профиль привязан к токену в localStorage этого браузера. Для переноса на другое устройство подключи VK ID.
- PWA-кэширует интерфейс и статические файлы; операции с коллекцией и подбором требуют сети.
- В каталоге могут отсутствовать отдельные метаданные (режиссёр, актёры, страна, доступность на стримингах): интерфейс показывает только поля, которые реально есть в базе.
