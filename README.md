# Swipe&Watch — backend (FastAPI + Neon Postgres)

Сервер собирает колоду карточек (вкус + взвешенный рандом + антиповторы), хранит просмотренное,
а каталог подтягивает из Кинопоиска и iTunes/Apple TV. Фронт (`static/index.html`) отдаётся с того же домена.
В браузере нет ни ключей, ни внешних API.

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впиши DATABASE_URL (Neon), SECRET_KEY, KP_API_KEY, ADMIN_TOKEN
python -m scripts.sync_catalog  # первый импорт каталога (создаст таблицы)
uvicorn app.main:app --reload   # http://localhost:8000
```
Строку Neon вставляй как есть (`...?sslmode=require&channel_binding=require`) — код сам приведёт её к asyncpg.

## Каталог
`python -m scripts.sync_catalog [--budget 450] [--no-itunes]`
1. **Кинопоиск**: топ-250 фильмов/сериалов + выборки по 10 жанрам (по числу голосов) → черновики.
2. **Дообогащение**: по каждому фильму отдельный запрос за описанием, длительностью и возрастом.
   Бесплатный тариф ≈ 500 запросов/сутки (проверь свой), поэтому запускай раз в день — каталог копится.
3. **iTunes/Apple TV**: без ключа, сразу с описанием и постером; дубли с Кинопоиском отсекаются по «название+год».

В колоду попадают только фильмы с описанием и постером (`GET /api/admin/stats` → `ready_for_deck`).
Можно запускать и по HTTP: `POST /api/admin/sync` с заголовком `X-Admin-Token`.

## API (`/api`)
| метод | путь | что делает |
|---|---|---|
| POST | `/auth/anon` | выдаёт подписанный токен (клиент кладёт в localStorage) |
| GET | `/meta` | жанры и размер каталога |
| POST | `/sessions` | `{limit: 10/15/20, initial_genres[], surprise}` → первые 8 карточек |
| GET | `/sessions/{id}/next?n=5` | следующая порция; `planned_total` сжимается, если каталог кончился |
| POST | `/sessions/{id}/events` | свайпы (`right/left/up`+rating), идемпотентны по `event_id` |
| POST | `/sessions/{id}/undo`, `/finish` | отмена последнего свайпа / завершение |
| GET/DELETE | `/me/history` | просмотренное/лайки/скипы; сброс истории |
| GET | `/admin/stats`, POST `/admin/sync` | только с `X-Admin-Token` |

## Как работает колода (`app/services/deck.py`)
- Веса жанров = кластеры онбординга (+2) + свайпы (right +2, left −1, просмотр 1–5 → −2/−1/+1/+2/+3). Считаются из БД, undo не ломает.
- Вкус фильма = сумма весов жанров / √(числа жанров) — многожанровые не выигрывают автоматически.
- Выбор — **взвешенная выборка без возвращения** (Efraimidis–Spirakis), а не сортировка: лучшие выпадают чаще, но порядок каждый раз новый. `seed` хранится в сессии.
- ~20% карточек — «исследование» из жанров с нулевым/отрицательным весом (позиции 4, 8, 12).
- Не больше 3 подряд с одним основным жанром.
- Антиповторы: просмотренное — никогда; скип — 30 дней; лайкнутое и выданное в прошлой сессии — в последнюю очередь. Если свежих не хватает, добираем из «мягких» уровней.
- «Удиви меня» — почти равномерно среди фильмов с рейтингом ≥ 7.
- Уже выданные карточки сервер не переставляет, поэтому превью следующей карточки не «мигает».

## Тесты и деплой
`pip install -r requirements-dev.txt && pytest` (SQLite, без сети; 24 теста).
`Dockerfile` готов (Amvera умеет собирать из Dockerfile). Переменные — из `.env.example`.

## Что осталось на v2

режиссёр/актёры (`/v2.2/films/{id}/staff` = ещё запрос на фильм), долгосрочный профиль вкуса, Sentry.
